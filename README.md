# AcadAssist.ai

The first public version of **AcadAssist.ai — Your Academic Assistant**.

## Included in this release

- Quick Attendance Calculator
- Semester Attendance Planner
- Weekly timetable planner
- Editable college and state holiday calendar
- Automatic exclusion of India's national holidays

## Deploy to Cloudflare Pages

This is a plain static site. In Cloudflare Pages, use:

- Framework preset: `None`
- Build command: leave blank
- Build output directory: `/`

Every push to the connected GitHub repository automatically publishes the latest version.
